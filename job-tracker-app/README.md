# 📋 Job Tracker App

A mobile-first job application tracker built with HTML, CSS, and JavaScript. Works offline and can be installed on your phone as a PWA (Progressive Web App).

## ✨ Features

- ✅ Add/Edit/Delete job applications
- 📊 Statistics dashboard (Applied, Interviews, Offers, Rejected)
- 📈 Response rate calculation
- 🎨 Charts (Doughnut chart showing status distribution)
- 🌙 Dark mode toggle
- 💾 Local storage (data stays on your device)
- 📱 Mobile-first responsive design
- 🔌 Works offline (Service Worker)
- 🔍 Filter by status
- 📅 Date tracking

## 🚀 How to Install on Android

### Method 1: PWA Install (Easiest!)
1. Host these files on GitHub Pages or any static host
2. Open the URL in Chrome on your phone
3. Tap menu (⋮) → "Add to Home Screen"
4. App appears on your home screen like a real app!

### Method 2: Convert to APK
Use a tool like [PWABuilder](https://www.pwabuilder.com/) to convert to APK.

## 🛠️ Tech Stack

- HTML5
- CSS3 (Modern with CSS Variables)
- Vanilla JavaScript
- Chart.js (for charts)
- LocalStorage (for data)
- Service Worker (offline support)
