# 🐍 Python Quest - Learn Python by Playing!

A gamified RPG-style mobile app that teaches Python programming through interactive challenges. Install as a Progressive Web App (PWA) on your Android phone!

## 🎮 Features

- **6 Worlds** with **30+ challenges** teaching Python from basics to OOP
- **Real Python execution** in the browser using Skulpt
- **XP & Leveling system** - earn XP for each completed challenge
- **HP system** - 3 lives per challenge, make mistakes and lose HP
- **Achievements** - unlock special achievements for milestones
- **World Map** - visual progression through 6 themed worlds
- **Leaderboard** - compete with other Python learners
- **Offline support** - play without internet after first load
- **Mobile-optimized** - install as a native-like app on Android

## 🗺️ Worlds

1. **🌲 Forest of Beginnings** - Variables, print, strings, numbers
2. **🕳️ Cave of Conditions** - if/else, comparisons, logical operators
3. **🗼 Tower of Loops** - for loops, while loops, iteration
4. **📚 Library of Lists** - Lists, dictionaries, data structures
5. **🏛️ Temple of Functions** - Functions, parameters, return values
6. **🏰 Castle of OOP** - Classes, objects, inheritance

## 🛠️ Technology Stack

- **HTML5** - Structure
- **CSS3** - Styling with gradients and animations
- **JavaScript** - Game logic
- **Skulpt** - Python interpreter in the browser
- **localStorage** - Save progress locally
- **Service Worker** - Offline support
- **PWA** - Install as Android app

## 📱 How to Install on Android

1. Open **Chrome** on your Android phone
2. Visit: `https://ahish99.github.io/portfolio/python-quest/`
3. Tap **menu (⋮)** at the top right
4. Tap **"Add to Home Screen"** or **"Install App"**
5. Name it "Python Quest" and tap **Add**
6. The app icon will appear on your home screen! 🎉

```
World 1: print(), variables, strings, numbers

World 3: for loops, while loops, range()
```
